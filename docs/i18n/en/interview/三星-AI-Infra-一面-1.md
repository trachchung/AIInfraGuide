The following is what Samsung AI Infra first-round interviews covered, with emphasis on embedded systems and C++ basics.

### Project experience

1. Introduce your background and projects in English
2. Pick one project and explain it in detail
3. Purpose and implementation of high-concurrency design in the project

### C++ and data structures

4. Role and use cases of the `static` keyword
5. Rules and implementation of C++ function overloading
6. Design patterns: describe how to implement the singleton pattern
7. Can a constructor be virtual, and why?

### Networking and algorithms

8. TCP three-way handshake and four-way teardown
9. Properties of DFS and BFS, data structures used, and typical applications

### Coding

10. Find the position of the first 1 in an ordered binary string "000...0111...1"
11. Check whether a string is a palindrome

### Other

12. Basic Linux operations
